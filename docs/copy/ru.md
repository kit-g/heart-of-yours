# Russian copy review — #442

Reviewed all **1,024 app strings**, **103 native strings** and **134 release-note titles and bodies** in the locale. The English source and usage context were considered for each entry. This pass changes **249 translation entries** (21 native) and **55 release-note fields**. Unchanged strings have no findings row. User review of this log is in progress.

Source issue: [Copy: review and rework the Russian copy](https://github.com/kit-g/heart-of-yours/issues/442). No store listings or Play release notes are included.

Use polite «вы» without formal capitalisation. Button acknowledgements avoid gendered past tense. Use ё consistently in changed copy, «ёлочки» for quoted names, and spaces between numbers and unit symbols. The English motto is deliberately unchanged: its source metadata identifies it as a fixed brand tagline.

Validation messages describe the problem neutrally rather than command the user. User review retained «Не может быть пустым» for `cannotBeEmpty`; «Заполните поле» sounds rude in this context. The retained string has no findings row.

User review retained the original spoken Siri request for `iosShortcutPhraseLastExercise`: «Когда я в последний раз делал ${exercise} в ${applicationName}». It has no findings row because it is unchanged from the base version.

User review also retained «Бицепс бедра» and «Приводящие» for the muscle-map labels. Familiar gym terminology takes priority over added anatomical precision for these labels; neither retained string has a findings row.

## Source questions and constraints

- `miles` has only `=1` and `other`, so values such as 5 currently produce «5 мили». Adding Russian `one`/`few`/`many` forms would change the ICU structure, which the issue explicitly says to preserve. That permission question is pending; the string is unchanged and remains a known defect. All changed entries preserve their complete existing ICU branch structure and placeholders.
- `accountDeleted` says “Account deleted” while the body describes scheduled deletion and offers reversal. The Russian title keeps the source meaning; the English ticket should decide whether the title should instead say deletion is scheduled.
- `patternHelp` compares movement patterns with equipment and body parts as if they formed one hierarchy. The Russian explains the concept through familiar movements and substitutable exercises; the English wording needs clarification.
- `recoverBody` mixes a lost journey, a pause and resetting together. The recovery screen concerns account access; the Russian states that access can be restored and training can continue.
- `resetPasswordBody` says there is “no turning back” before acknowledging cancellation. The Russian keeps the light tone and explicitly says cancellation is still possible; the English ticket should remove the conflicting warning.
- `emptyExerciseHistoryBody` relies on a Monday-morning gym being empty. The comparison is retained, but the English ticket should decide whether this joke belongs in the empty state.
- The app’s health write-back subtitle describes duration only, while the native permission text also names workout type. No health behaviour or scope is changed here; reconcile that source wording in the English pass.

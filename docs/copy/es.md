# Spanish copy review — #440

Reviewed all 1,127 `es` entries in the master CSV (1,024 app strings and 103 native strings), plus all 134 title/body fields in the 67 in-app release-note items across 20 versions. Store listings and Play release notes are outside this ticket.

Changed 175 CSV entries (159 app, 16 native) and 53 release-note fields. The tables below contain one row per changed string; unchanged strings are omitted. Neutral Spanish with the established tú register. Familiar gym terms and short labels are kept when they already read naturally. Validation messages remain neutral, and exercise names are not put in quotation marks.

## Patterns

The recurring problems were literal English metaphors in account, import and API copy; ambiguous pronouns; and inconsistent names for training, goals and movement filters. The changes describe the actual action, data or result, while retaining the existing friendly register. Filter help distinguishes technical skill from physical fitness, progression rules distinguish missed targets from short sessions, and chart labels identify the metric being plotted. Release notes use the revised app labels. The native pass follows the same terminology without changing permissions or the device-only health-data promise.

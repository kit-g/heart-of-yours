# 1.11.0

## Warm-ups, drop sets and failure sets

Tap a set's number to mark it as a warm-up (W), a drop set (D) or a failure set (F); tapping the
type a set already has makes it plain again, and a "?" beside each type explains it in place. Only
plain sets are numbered, so a warm-up, two working sets and a failure set read W, 1, 2, F. Adding
a set always adds a plain one.

Warm-ups stay out of your personal records, every exercise chart and the muscle map; drop and
failure sets count like any other. The Previous column lines warm-ups up with last time's
warm-ups and working sets with working sets. Your Apple Watch shows the same letters, numbered
the way the phone numbers them.

Set types travel with your workouts, templates included: a template's warm-ups start as warm-ups.
A Strong import keeps them, and editing an imported workout no longer turns them back into plain
sets.

## RPE, if you want it

Rate how hard each set felt, from 6 to 10 in half steps, from the same menu on its number. A "?"
unfolds the scale (10: not one more, down to 6: four or more), a × clears a rating, and a rated
set carries a small "@8" on the corner of its last value. RPE is off until you turn it on in
Settings › Features. Ratings from a Strong import are kept either way, and appear when you do.

## A note on the whole workout

Add a note to a workout from its ⋯ menu, while you train or later from History. It shows on the
workout's card in History, and syncs with the rest of the workout.

## Muscles worked, per workout

With the muscle map on, every finished workout shows which muscles it worked: on the summary
right after you finish, and on its page in History. Each muscle group is shaded by how many sets
it got; tap one for its number. It is one of the muscle map's parts in Settings › Features.

## Fill a column at once

Tap kg or Reps above an exercise's sets to fill every set not yet done from the top one, and the
✓ above them to tick every set that can be ticked; tap it again to untick them all.

## Also

- Starting a workout while another is running now asks before replacing it, and the replaced one
  is removed rather than left behind.
- Tapping the Live Activity while the workout is already on screen leaves it where it is.
- Settings › Features is a page of its own, and a What's new note about a feature takes you
  straight to its switch.
- Screen readers announce the set table's column headings and the rest-timer button.

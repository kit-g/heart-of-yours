# 1.17.2

Android only. Two fixes: a crash on finishing a workout that 1.17.0 brought in, and exercise names that could stay in English on a phone set to Russian.

## Finishing a workout closed the app

With Health Connect on, finishing a workout writes it to Health Connect as an exercise session. A dependency update in 1.17.0 replaced the Health Connect library with a version that no longer has the call that write makes, so the app closed as the workout finished. The library is back on the version the write was built against, and is held there until the code that writes the session supports a newer one.

## Exercise names could stay in English on a phone set to Russian

The exercise library is downloaded once per language, along with a note saying which language and version the phone has. Each launch, the app compared that note with the phone's language, never with the names, so a phone whose note said Russian over English names kept them. The app now checks the names as well, and downloads the library again when they don't match the note.

Changing the phone's language while a download couldn't go through, for example while offline, also left the names in the old language until the app was restarted. The app now tries again every time it comes back to the foreground.

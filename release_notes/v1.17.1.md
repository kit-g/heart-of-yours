# 1.17.1

Both stores. Five fixes, four of them from the first week of feedback on 1.17.0 from a lifter training in Russian on a Galaxy S21, the fifth found while fixing one of them.

## Closing the new-exercise dialog mid-save crashed the next Back

Creating or editing your own exercise saves it to the server before the dialog closes. Closing the dialog during that save, with Back, the close button or a tap outside, let the save finish afterwards and close whatever route was on top by then. That was usually the screen behind the dialog. The app carried on, but the next press of Back found no navigator to pop and crashed (`Bad state: No element`).

The dialog now stays open while a save is in flight, and when the save finishes it closes only itself.

## A long exercise name pushed the workout header's buttons off screen

An exercise name longer than the row, common for your own exercises and in Russian, pushed the rest timer and the more-options button past the edge of the screen, where they could not be tapped. The name now wraps to a second line and is cut short after that. The buttons always keep their place.

## A History card could show a best set for an exercise done ×0

A History card's exercise line counted ticked sets for its ×N but took its best set from every set but warm-ups, ticked or not. The total volume did the same. When a workout held a set that was never ticked, the card could read "×0" beside a best set and count that set's weight in the volume. The card's best set, volume and fallback now count ticked sets only, matching the ×N. How an unticked set reached that workout is still being looked into.

## Weekly goals on a top set or estimated 1RM didn't draw on charts

A goal draws as a line on its exercise's charts and on its Profile chart. Goals with a weekly or monthly period were left off on purpose, because a goal that adds up a week, such as volume, has no single session to compare against. That also hid goals like "a 100 kg top set this week", which is one session's number. Weekly and monthly goals on a best or an average now draw; goals that add up a period still don't.

## Android tablets: Back on Exercises or History with nothing selected crashed

On a tablet, Exercises and History show a list and a detail pane side by side. With nothing selected, the detail pane's navigator wasn't built at all, so Back on that tab found nothing to pop and crashed (`Null check operator used on a null value`). The navigator is now always there, kept off screen while nothing is selected. Phones were never affected, and iPads have no Back button.

## Releasing

The Play production upload is now sent as a change that is not submitted for review, so a Console that is still holding other changes can't refuse it. This is what failed 1.17.0's first attempts. 1.17.0's entry in the in-app What's new list is dated 2026-11-04, its first production deploy.
